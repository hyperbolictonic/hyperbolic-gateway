Local-first agent tooling

A real browser.
A real API surface.

Hyperbolic Gateway pairs a visible Chromium browser with a typed REST bridge for AI agents, running on your machine. No cloud browser, no account, no separate Node install.

Open the manual Browse documentation

Two surfaces, one local app

Hyperbolic Browser drives a real browser. Hyperbolic Rest turns HTTP APIs into saved, typed tools. Both share local storage, credentials and the same bridge.

hb-browser

Hyperbolic Browser

Visible Chromium, humanized input, tabs, downloads, Cortex memory and Shadow Walk controls for agents.

 hb-rest

Hyperbolic Rest

Saved wrappers, typed arguments, response recipes, pagination and host-bound encrypted credentials.

 local-first

Own the machine

Windows, Linux and Apple Silicon builds. No hosted browser, account or remote dashboard.

Start in three steps

Open a page

Use the address bar and normal browser UI. Tabs, cookies, downloads and history work as expected.

Connect an agent

Open Settings → MCP Clients. Use hb-browser or hb-rest; legacy aliases remain available.

Let it work

The agent reads pages, acts with human-like input, or calls saved REST wrappers with typed arguments.

Legacy & inspiration

Hyperbolic Gateway was previously named Kuang Grade Mark Eleven. Existing MCP labels, environment variables and wrapper files are kept as compatibility aliases.

"A Kuang Grade Mark Eleven penetration program. Icebreaker. The military stuff, the heavy artillery."

The original name and quote are preserved as inspiration. Hyperbolic Gateway is an independent project and is not affiliated with William Gibson, Neuromancer, or the fictional device.
