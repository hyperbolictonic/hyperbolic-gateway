# 🛠️ Kuang Grade Mark Eleven — Scripts Directory

This directory contains utility scripts, automated test harnesses, and the standalone MCP stdio server executable.

---

## 📜 Key Scripts

### 1. Model Context Protocol Server
- **[`mcp-server.js`](./mcp-server.js)** & **[`bin/mcp-server.cjs`](../bin/mcp-server.cjs)**:
  The standalone MCP stdio server executable communicating with LLM clients (Claude Desktop, Cursor, Antigravity, Agent-Orcha) over standard I/O (`stdio`). Exposes all 81 registered (59 advertised) standardized browser navigation, multimodal vision, visual grounding, orthogonal primitives, LLM-friendly discovery, web search, deep crawl, autonomous research, tab management, session/context vault, network stream interception, script recall, system tray, and human-in-the-loop tools by translating them into HTTP calls against the chassis bridge (`http://127.0.0.1:4111`).
  > Both files are generated by `npm run build:mcp` from [`src/mcp/bridge-server.ts`](../src/mcp/bridge-server.ts) and are byte-identical mirrors — `bin/` is the canonical entry point, `scripts/` is kept for the test harnesses. Never hand-edit either; see the **Diagnostics & stdio Discipline** section in [`src/mcp/README.md`](../src/mcp/README.md) before touching logging.

### 2. Automated Test Suites
- **[`test-primitives.mjs`](./test-primitives.mjs)** (`npm run test:primitives`):
  Offline fixture suite (25 checks) for the orthogonal primitive layer: `wait_for` (selector/text/delayed), `extract` list/table/app_data, `observe` budget+cursor+text, `collect_all` over a virtualized list, `find` + `act` (type/click) + delta, `expect`, `page_state`/`diff`, and `bridge_health` capabilities.
- **[`test-mcp-primitives.mjs`](./test-mcp-primitives.mjs)** (`npm run test:mcp:primitives`):
  Drives the same primitives through a real MCP stdio client (tool schemas, viewport gating, `find`→`act`, `context_*`, `set_window_visibility`).
- **[`test-llm-surface.mjs`](./test-llm-surface.mjs)** (`npm run test:llm`):
  Bridge-level regression for LLM-friendly discovery (Feature 6). Starts local fixture origins and asserts `llm_surface` finds `/llms.txt` / `/sitemap.xml` / a `<link rel="alternate">`, that `llm_fetch` is gated (`NO_LLM_SURFACE`), and that per-page alternates load via a real navigation. SKIPs when the bridge is down.
- **[`test-search-web.mjs`](./test-search-web.mjs)** (`npm run test:search`):
  Bridge-level regression for `search_web` (Feature 5). Drives the `custom` engine against a local fixture SERP and asserts result parsing, `max_results`, engine-chain fallback, `blocked` detection, and `BAD_REQUEST` on an empty query. SKIPs when the bridge is down.
- **[`test-deep-crawl.mjs`](./test-deep-crawl.mjs)** (`npm run test:crawl`):
  Bridge-level regression for `deep_crawl` (Feature 1). Crawls a local fixture link graph and asserts depth/paging budgets, `match_patterns` scoping, same-origin enforcement, the content-negotiated Markdown fast path, and Cortex indexing. SKIPs when the bridge is down.
- **[`test-research-topic.mjs`](./test-research-topic.mjs)** (`npm run test:research`):
  Bridge-level regression for `research_topic` (Feature 3). Drives the whole pipeline against a fake SERP + article fixtures and asserts source gathering, extractive highlights, the Markdown fast path, `max_sources`, Cortex indexing, and `BAD_REQUEST`. SKIPs when the bridge is down.
- **[`test-input-focus-independence.mjs`](./test-input-focus-independence.mjs)** (`npm run test:focus`):
  Hands the OS foreground to another application (Notepad) and asserts typing/clicks/wheel still land **and** that the active transport is `cdp`.
- **[`test-harvest-regression.mjs`](./test-harvest-regression.mjs)** (`npm run test:harvest`):
  End-to-end markdown/marks harvest regression (including off-screen marks).
- **[`test-chaos-engine.js`](./test-chaos-engine.js)**:
  Benchmarking and live verification suite for the Bio-Kinematic Chaos Engine. Validates lag-1 autocorrelation ($1/f$ pink noise tremor), asymmetric minimum-jerk acceleration curves, ballistic target overshoots, and saccadic micro-corrections.
- **[`test-tray-and-hil.js`](./test-tray-and-hil.js)**:
  Verifies system tray visibility toggling, close-to-tray configuration, native desktop notification dispatch, and human-in-the-loop (HIL) intervention request and resolution flow.
- **[`test-realtime-streams.js`](./test-realtime-streams.js)**:
  Connects to a real WebSocket echo feed (`wss://ws.postman-echo.com/raw`) and tests live CDP WebSocket/SSE duplex message frame interception, message limits, and buffer clearing.
- **[`test-script-vault.js`](./test-script-vault.js)**:
  Saves DOM extraction macros, verifies LanceDB semantic vector embedding, tests natural language macro search (`list_scripts({ query })`), and validates runtime parameter injection (`run_script`).
- **[`test-set-of-marks.js`](./test-set-of-marks.js)**:
  Tests Set-of-Marks (SoM) visual grounding by injecting numbered neon badges over interactable DOM nodes, taking annotated screenshots, and actuating Bézier clicks on badge IDs.
- **[`test-network-interceptor.js`](./test-network-interceptor.js)**:
  Attaches CDP network listeners, captures background XHR/Fetch JSON API responses, and verifies `get_network_traffic` and `get_api_payload`.
- **[`test-session-vault.js`](./test-session-vault.js)**:
  Tests snapshotting cookies and localStorage into persistent JSON files and rehydrating them across browser sessions.
- **[`test-downloads.js`](./test-downloads.js)**:
  Verifies download interception into `./data/downloads/`, PDF/CSV/JSON text extraction, and automatic ingestion into LanceDB Cortex.
- **[`test-fill-form.js`](./test-fill-form.js)**:
  Tests single-turn batch form population (`fill_form`) across text inputs, selects, checkboxes, and radios with human typing cadence.
- **[`test-shield-breaker.js`](./test-shield-breaker.js)**:
  Validates autonomous OneTrust, Cookiebot, and Google GDPR consent banner detection and dismissal.
- **[`test-mcp-cortex.js`](./test-mcp-cortex.js)**:
  Connects a test client to `mcp-server.js` over stdio and executes `recall_memory`, `get_history`, `list_bookmarks`, and `add_bookmark` calls to verify end-to-end LanceDB vector recall.
- **[`test-cortex.js`](./test-cortex.js)**:
  Navigates the chassis, ingests web pages, chunks markdown, saves bookmarks, and tests hybrid vector + BM25 full-text recall against the HTTP bridge.
- **[`test-mcp-tabs.js`](./test-mcp-tabs.js)**:
  Spawns, switches, lists, and closes multiple isolated browser tabs via MCP tools.
- **[`test-client.js`](./test-client.js)**:
  Basic smoke test for the initial MCP navigation and click toolset.

  Validates unstyled/transparent webpage background color rendering.
- **[`test-screenshot.js`](./test-screenshot.js)**:
