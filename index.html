HUMAN INPUT

How the cursor and keyboard move. The defaults aim at a comfortable fast human; lower them for a more deliberate, harder-to-spot cadence, raise them when a flow feels slow. Saved to data/input-profile.json and applied live.

Pointer speed — 1400 px/s

Glide time is derived from distance ÷ speed. 1400 px/s crosses 500px in ≈360 ms; 3000+ feels like a gaming mouse; 600 is a careful human.

Typing — 220 wpm

5 characters per word. 220 wpm ≈ 55 ms per keystroke, with extra deliberation on spaces and punctuation. 120 wpm is a normal human; 400+ is transcription speed.

Click dwell — 55 ms

Pause before pressing and how long the button is held. 0 is instant and slightly synthetic; 40–80 ms looks human.

    RESEARCH & STEALTH

    Controls for search_web, deep_crawl, and research_topic. Stealth mode uses a separate research session, optional proxy, provider preference, politeness delays, and per-domain backoff after WAF/challenge pages. It does not bypass CAPTCHAs.

    Search engine chain

    Comma or > separated. Order matters. DuckDuckGo/Brave are gentler than Google.

    Custom search template (optional)

    A SearXNG instance or another provider URL containing {query}. When set, it is tried first.

    Research proxy (optional)

    Applied only to the isolated persist:kuang-research session, not your normal browsing tabs.

    Domain cooldown (seconds)

    After a WAF/challenge or 403/429, the host is paused and not retried.

    Politeness delay (ms)

    Minimum delay between crawled pages and research sources.

    Crawl concurrency

    1 is sequential and safest. Higher values fetch pages in parallel and raise WAF risk.

    KUANG WRAP

    Browse and edit saved REST wrappers, and manage the host-bound credentials they reference. Wrapper files never contain credential values. Values are encrypted by the OS keychain, stay in the main process, and are never returned to an agent.

    SAVED WRAPPERS

    Select one to edit it. This is the same store agents use through kuang-wrap.

      Select a wrapper to edit it in the editor modal, or press NEW to start one.

      CREDENTIALS

      A wrapper references one by name in request.auth. The value is write-only; leave it blank while editing to keep the current one.

      Secret name

      Lowercase letters, numbers, dot, dash, underscore; starts with a letter. A wrapper references it exactly as written.

      Header
      Credential type

      OAuth2 uses only the client_credentials grant: it posts to the token URL, caches the token until it expires, and re-mints on demand. It does not support authorization-code, device flow, or refresh tokens.

      Token URL
      Client ID
      Scope (optional)
      Value (write-only)

      For an OAuth2 credential this is the client secret; it is encrypted and never leaves main.

      Allowed hosts

      Exact hosts, or *.example.com for subdomains. A wrapper on any other host is refused.

      Prefix

      For Authorization, the scheme and space. Leave empty for an API-key header.
