# 🌐 Kuang Grade Mark Eleven — Public Web Root

This directory contains static HTML documents, icons, and media assets served or rendered directly by the Chromium chassis.

---

## 📄 Files & Directories

- **[`welcome.html`](./welcome.html)**:
  The built-in Cyberdeck Manual screen. Automatically loaded when opening empty tabs (`mark-eleven://manual` or `about:blank`), presenting system architecture principles, the Dade Murphy cyberpunk quote, the *Grade Eleven is a Web Browser for your Local AI* tagline, and the interactive MCP command reference.
- **[`assets/`](./assets/README.md)**:
  Tactical high-resolution emblems and branding logos for the Ono-Sendai 7 deck, Kuang Grade icebreaker, and Mark Eleven tactical core.
