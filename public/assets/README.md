# 🎨 Hypagon Gateway — Brand Assets

This directory stores the official graphical emblems and icons for **Hypagon Gateway**.

## Current brand

1. **`brand/hypagon-lockup.png`** — the canonical lockup: emblem, HYPAGON wordmark and
   `Browser automation. Local intelligence.` on the dark plate (1254×1254). Used by the README.
2. **`brand/hypagon-icon-transparent.png`** — the transparent emblem with the H monogram
   (1358×1159). **Source of the app icon and favicon**; keep this file when the art changes.
3. **`brand/hypagon-gateway-primary.png`** — 1024×1024 app, installer, window, tray and
   notification icon. Square crop of `hypagon-icon-transparent.png`, centred with ~6% padding.
4. **`brand/hypagon-favicon.png`** — 256×256 browser favicon, same crop.
5. **`brand/HyperGateway3.jpg`** — earlier source artwork for the previous H-mark (2048×2048).
6. **`brand/HyperGateway2.jpg`** — alternate dark-square H-mark source (2048×2048).
7. **`brand/Hypergateway1.jpg`** — alternate wide H-mark artwork (2400×1792; checkerboard background baked into the JPG).

Regenerate the icon and favicon from `hypagon-icon-transparent.png` whenever the emblem
changes — the crop is a square centred on the artwork's alpha bounding box, sampled with
alpha-weighted interpolation so transparent edges never pick up a white fringe.

## Legacy assets

The original Kuang Grade / Mark Eleven emblems are retained for historical and compatibility
purposes:

- `ono-sendai.png` — Ono-Sendai Cyberspace 7 emblem
- `kuang-grade.png` — original Kuang Grade crest
- `mark-eleven.png` — original Mark Eleven tactical emblem

These are not the current product identity.
