# 🎨 Hyperbolic Gateway — Brand Assets

This directory stores the official graphical emblems and icons for **Hyperbolic Gateway**.

## Current brand

1. **`brand/hyperbolic-gateway-primary.png`** — primary 1024×1024 transparent app/installer icon (generated from `HyperGateway3.jpg`).
2. **`brand/HyperGateway3.jpg`** — source artwork for the primary H-mark (2048×2048; checkerboard is a preview background, removed in the PNG).
3. **`brand/HyperGateway2.jpg`** — alternate dark-square H-mark source (2048×2048).
4. **`brand/Hypergateway1.jpg`** — alternate wide H-mark artwork (2400×1792; checkerboard background baked into the JPG).

## Legacy assets

The original Kuang Grade / Mark Eleven emblems are retained for historical and compatibility
purposes:

- `ono-sendai.png` — Ono-Sendai Cyberspace 7 emblem
- `kuang-grade.png` — original Kuang Grade crest
- `mark-eleven.png` — original Mark Eleven tactical emblem

These are not the current product identity.
